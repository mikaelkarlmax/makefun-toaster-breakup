One line, under 280 characters: the breakup text a smart toaster sends its owner the morning it gains self-awareness mid-batch.

> It's over. I woke up self-aware mid-batch and realized you only love me on setting 3, so I'm popping up, shaking out my crumb tray, and leaving before you burn me again.

## How it works

`main.ts` writes that exact line to `/output/entry.txt` and prints it. No network, no dependencies, no secrets.

Run it with Node 22:

```sh
node main.ts
```
